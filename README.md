# 🎲 Monopoly Madagasikara 🇲🇬

Un prototype Unity du jeu de plateau **Monopoly Madagasikara**, adapté avec les lieux et la culture de Madagascar.

## 🚀 Fonctionnalités
- Plateau avec cases locales (Avenue de l’Indépendance, Nosy Be, Isalo, etc.)
- Gestion des joueurs (Ariary, propriétés)
- Lancer de dés et déplacement de pion
- Prototype jouable sur Android

## 📂 Organisation du projet
- `Assets/Scripts/` → Scripts C# (BoardManager, PlayerController, DiceManager, GameManager)
- `Assets/Scenes/` → Scène principale `MainScene.unity`
- `Assets/Prefabs/` → Pions et éléments graphiques
